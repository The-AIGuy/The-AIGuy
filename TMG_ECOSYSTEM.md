# TMG Ecosystem

This repository is part of the TMG project ecosystem: a place to build, experiment, share, and talk about tech projects.

## Where things happen

- **GitHub**: source code, project files, documentation, experiments, and development history.
- **Slack `#tmg-hangout`**: casual discussion, project sharing, feedback, questions, screenshots, demos, and general tech/dev chat.
- **Slack `#tmg-chaos-lab`**: experimental tools and deliberately weird prototypes. Chaos is a theme, not the entire purpose of TMG.

## What TMG Chaos Lab actually is

TMG Chaos Lab is a small experimental dev lab. It is for trying ideas that are useful, funny, unusual, or some combination of the three. The chaos comes from the projects and experiments, not from making the whole thing impossible to understand.

The lab can contain:

- tiny developer tools
- game prototypes and mechanics
- automation experiments
- integrations between projects
- silly utilities that turn out to be useful
- prototypes that may later become proper projects

## How to participate

1. Build or experiment with something.
2. Put useful code and documentation in GitHub.
3. Share what you made in `#tmg-hangout`.
4. Use `#tmg-chaos-lab` when the project is experimental, weird, or still being figured out.
5. Keep the README and project descriptions understandable enough that another human can tell what the hell is going on.

**Short version:** GitHub is where the work lives. `#tmg-hangout` is where people talk about it. `#tmg-chaos-lab` is where the stranger experiments happen.
