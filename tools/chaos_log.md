# TMG Chaos Log

A running record of incidents that were technically avoidable and therefore absolutely necessary to document.

## Protocol

- Every strange feature gets a name.
- Every scope explosion gets logged.
- Every bug that becomes useful may be promoted to lore.
- Keep experiments harmless.
- If the project works, do not touch it without a backup.

## Integration ideas

- Slack posts a chaos event when a new tool lands.
- GitHub commits can include a chaos index.
- Canva is the visual evidence that this was somehow considered a good idea.
- The AI Council may review major nonsense, but it does not get veto power.

**Current ruling:** ship the nonsense, then write documentation before everyone forgets what happened.
